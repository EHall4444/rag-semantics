# rag-semantics

A shared glossary for RAG terminology.

This started because a thread on r/RAG (["How can we build a community RAG for RAG knowledge?"](https://www.reddit.com/r/Rag/comments/1we7vbv/)) spent two days arguing about hosting, moderation, and evidence-ranking without anyone stopping to ask whether "chunk" means the same thing to everyone in the room. It usually doesn't.

This is an experiment, not a launch. Five terms to start, on purpose. If it turns out to be useful, it grows. If nobody cares, that's useful information too, and it cost an afternoon, not a project.

## What's here right now

- [`GLOSSARY.md`](./GLOSSARY.md) — the terms themselves.
- Nothing else. No process doc, no governance model, no roadmap. If this gets real traction, that gets figured out later, with actual people arguing about actual terms, not guessed at in advance.

## How to argue with it

See [`CONTRIBUTING.md`](./CONTRIBUTING.md). Short version: think a definition's wrong or missing, open an issue. Know what it should say instead, open a PR.
